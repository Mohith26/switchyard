The real thing

This page is a replay. The repo is a working gateway.

The experiments above can't run in a browser tab: they need real processes crashing, real sockets and real signals. So the page plays back recordings, and the code that produced them is on GitHub, where it builds, passes its tests on every push, and runs in front of ordinary HTTP servers.

What's in the repo

  • One Go binary with five roles: edge, cache, origin, loadgen and lab. Standard library only, no dependencies.
  • 61 tests, including tests that start the real binary as a separate process and send it real SIGHUP and SIGUSR2 signals.
  • CI on every push: the race-detector test suite on Linux, benchmarks, a shortened lab run, and a Docker Compose stack that has to serve a cache miss, then a hit, then survive a hot reload.

Where it works

  • Linux and macOS, with Go 1.23+ or Docker. Tested on Apple Silicon macOS and on Ubuntu x86-64 in CI.
  • In front of any plain-HTTP server. It caches GET responses that send Cache-Control: max-age, passes everything else straight through, and never shares a cached response between requests that carry cookies or an Authorization header.
  • That is checked two ways: a test against a server that knows nothing about Switchyard, and examples/front-a-python-server.sh, which fronts a ten-line Python server and restarts the edge during 400 requests without dropping any of them.
  • lab run re-records every number on this page in about seven minutes.

Where it doesn't

  • It is not a production CDN. There is no HTTPS: no TLS termination and no TLS to the origin. It speaks HTTP/1.1 only, with no HTTP/2 or QUIC.
  • There is one edge instance, so rate limits and concurrency limits are per process, not shared across a fleet.
  • The cache is in memory and sized by entry count. It starts empty after a restart.
  • Windows is not supported, because restarts rely on Unix signals and file-descriptor passing.
  • These numbers were measured on one machine over loopback. They show how much each mechanism changes the outcome, not internet-scale throughput.
